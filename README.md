# HLC Engenharia — Site Institucional

Site institucional da **HLC Engenharia**, escritório de projetos de instalações prediais com foco em metodologia BIM.

## 🌐 Publicação no GitHub Pages

### Passo 1 — Criar repositório
1. Acesse [github.com](https://github.com) → **New repository** → nome: `hlc-engenharia` → Public → criar

### Passo 2 — Enviar arquivos
No repositório criado, clique em **"uploading an existing file"** → arraste os arquivos → **Commit changes**

### Passo 3 — Ativar GitHub Pages
**Settings → Pages** → Source: `main` / `/ (root)` → **Save**

Aguarde ~2 min. O site estará em: `https://seu-usuario.github.io/hlc-engenharia`
